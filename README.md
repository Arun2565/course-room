# Course Room

Public course reader: Stanford CS231A / CS329A / CS336 lecture pages with
my highlights and margin notes. Read at https://arun2565.github.io/course-room/

Built from the private reading-room with `python3 tools/export_course_room.py`.
Lecture transcripts, slides and figures belong to Stanford / the lecturers;
notes in the margin are mine. If anything here should not be public, open an
issue and it comes down.
